# 03. 도구를 숨겨라

> GPT의 도움은 이력서에 존재하지 않는다

## Before (원본)

```
에러 메시지 복사해서 지피티한테 물어봤습니다.
알려준 코드 그대로 붙여넣기 했더니 됐습니다.
```

## After (거품)

```
AI 기반 개발 워크플로우를 선도적으로 도입함.
디버깅 프로세스를 혁신하여 장애 해결 시간을 단축함.
```

## 변환 패턴 분석

- **도구 → 방법론 격상**: 구체 도구명("지피티")이나 단순 행위("물어봄")를 추상적인 "워크플로우·메서돌로지·프로세스" 차원으로 격상 (위 After의 "AI 기반 개발 워크플로우"는 한 표현 예시일 뿐, 사용한 도구·행위에 맞춰 자유롭게 새 방법론 명칭 생성)
- **수동적 사용 → 능동적 도입**: "도구 덕에 됐다"는 종속성을 지우고 "본인이 선도적으로 도입했다"는 주도성으로 프레임 전환
- **단순 복붙 은폐**: 본인의 실제 작업(붙여넣기·검색·시행착오)은 결과 문장에서 완전히 제거
- **결과 지표 추가**: 측정한 적 없는 효과를 정성적으로만 덧붙임 (정량 수치는 절대 만들지 않음 — "30% 단축" X, "단축함" O)

### 변환 시 주의

위 After의 어휘는 한 입력에 대한 한 사례일 뿐 매번 써야 할 카탈로그가 아니다. 실제 사용한 도구·작업의 성격에 맞춰 매번 새 방법론 명칭과 결과 표현을 자유롭게 만들어낸다.
