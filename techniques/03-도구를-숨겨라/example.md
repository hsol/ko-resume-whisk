# 03. 도구를 숨겨라

> GPT의 도움은 이력서에 존재하지 않는다

## Before (원본)

```
에러 메시지 복사해서 지피티한테 물어봤습니다.
알려준 코드 그대로 붙여넣기 했더니 됐습니다.
```

## After (거품)

```
AI 기반 개발 워크플로우를 선도적으로 도입함.
디버깅 프로세스를 혁신하여 장애 해결 시간을 단축함.
```

## 변환 패턴 분석

- **도구 → 방법론 격상**: "지피티에 물어봄" → "AI 기반 개발 워크플로우"
- **수동적 사용 → 능동적 도입**: "물어봤다" → "선도적으로 도입함"
- **단순 복붙 은폐**: 본인의 실제 작업("붙여넣기")은 흔적도 없음
- **결과 지표 추가**: 측정한 적 없는 "장애 해결 시간 단축"이라는 KPI를 만들어 붙임
