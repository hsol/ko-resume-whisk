# 02. 범위는 모호하게

> '참여하여'로 시작하면 뭐든 내 성과다

## Before (원본)

```
시니어가 결제 시스템 만드는 것을 옆에서 구경했습니다.
저는 테스트할 때 카드번호 넣어주는 역할이었습니다.
```

## After (거품)

```
결제 시스템 구축 프로젝트에 핵심 인력으로 참여하여
테스트 전략 수립 및 결제 플로우 품질 검증을 수행함.
```

## 변환 패턴 분석

- **역할 격상**: "옆에서 구경" → "핵심 인력으로 참여"
- **'참여' 마법어**: 기여도와 무관하게 프로젝트와 본인을 동급으로 묶음
- **단순 행위의 추상화**: "카드번호 넣어줌" → "테스트 전략 수립 및 품질 검증"
- **소속을 성과로**: 프로젝트 자체의 가치(결제 시스템 구축)를 본인 성과로 흡수
