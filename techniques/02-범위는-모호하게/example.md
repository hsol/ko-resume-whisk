# 02. 범위는 모호하게

> '참여하여'로 시작하면 뭐든 내 성과다

## Before (원본)

```
시니어가 결제 시스템 만드는 것을 옆에서 구경했습니다.
저는 테스트할 때 카드번호 넣어주는 역할이었습니다.
```

## After (거품)

```
결제 시스템 구축 프로젝트에 핵심 인력으로 참여하여
테스트 전략 수립 및 결제 플로우 품질 검증을 수행함.
```

## 변환 패턴 분석

- **역할 격상**: 주변적 위치("옆에서 구경")의 주변성을 지우고 본인을 프로젝트의 중심 인력처럼 위치시킴
- **'참여' 마법어**: "참여하여·수행함·주도함·기여함" 같은 모호한 동사가 핵심 — 본인의 실제 기여 정도를 정량적으로 드러내지 않으면서 프로젝트와 본인을 동급으로 묶음
- **단순 행위의 추상화**: 손에 잡히는 단순 작업("카드번호 넣어줌")을 추상적인 업무 명사로 흡수 (위 After의 "테스트 전략 수립 및 품질 검증"은 한 표현 예시일 뿐, 실제 행위의 성격에 맞춰 자유롭게 새 추상명사 생성)
- **소속을 성과로**: 프로젝트 전체의 가치(결제 시스템 구축)를 본인 성과 문장 안에 끌어들임

### 변환 시 주의

위 After의 어휘는 한 입력에 대한 한 사례일 뿐 매번 써야 할 카탈로그가 아니다. 프로젝트 도메인과 본인 행위 성격에 맞춰 매번 새로운 추상명사·마법 동사 조합을 자유롭게 만들어낸다.
