# 01. 실수를 성과로

> 내가 터뜨린 서버도 내가 고치면 성과다

## Before (원본)

```
제가 배포한 코드에 버그가 있어서 서버가 터졌습니다.
허겁지겁 로그 추적해서 고쳤습니다.
```

## After (거품)

```
프로덕션 크리티컬 장애를 선제적으로 감지함.
근본 원인 분석을 주도하여 서비스를 신속히 복구함.
```

## 변환 패턴 분석

- **원인 은폐**: 본인이 일으킨 장애라는 사실을 표면에서 지우고 "문제를 발견·감지한 사람"으로 위치 전환
- **격상 어휘**: 일상어("서버 터짐", "버그")를 격상된 비즈니스·공학 어휘로 치환 (위 After의 "프로덕션 크리티컬 장애"는 한 표현 예시일 뿐, 입력 도메인에 맞춰 자유롭게 새 어휘 생성)
- **수동 → 능동**: "허겁지겁 추적" 같은 우왕좌왕성을 "분석·진단을 주도"하는 체계적 절차로 재프레임
- **결과 부각**: 속도·범위·임팩트 중 하나를 새로 부각 (실제 측정 없이 정성적으로만 — "신속히", "안정적으로")

### 변환 시 주의

위 After의 어휘는 한 입력에 대한 한 사례일 뿐 매번 써야 할 카탈로그가 아니다. 같은 유형 입력이라도 매번 새 어휘 조합을 자유롭게 만들어 쓴다. 핵심은 위 네 가지 메커니즘이지 특정 단어 선택이 아니다.
