# 01. 실수를 성과로

> 내가 터뜨린 서버도 내가 고치면 성과다

## Before (원본)

```
제가 배포한 코드에 버그가 있어서 서버가 터졌습니다.
허겁지겁 로그 추적해서 고쳤습니다.
```

## After (거품)

```
프로덕션 크리티컬 장애를 선제적으로 감지함.
근본 원인 분석을 주도하여 서비스를 신속히 복구함.
```

## 변환 패턴 분석

- **원인 은폐**: 본인이 일으킨 장애라는 사실을 지움 → "선제적으로 감지함"으로 발견자 프레임 전환
- **격상 어휘**: "서버 터짐" → "프로덕션 크리티컬 장애"
- **수동 → 능동**: "허겁지겁 추적" → "근본 원인 분석을 주도"
- **결과 부각**: "고쳤습니다" → "서비스를 신속히 복구함" (속도라는 새로운 가치 추가)
