# 05. 공백기를 전략으로

> 쉰 게 아니라 투자한 것입니다

## Before (원본)

```
퇴사하고 3개월 동안 집에서 넷플릭스 보면서 쉬었습니다.
가끔 유튜브로 코딩 강의 틀어놨습니다.
```

## After (거품)

```
지속 가능한 성장을 위해 Strategic Pause를 선택, 업계 트렌드를 분석함.
신규 기술 스택을 자기 주도적으로 학습하며 커리어 재정비의 시기를 가짐.
```

## 변환 패턴 분석

- **휴식 → 전략적 선택**: "쉬었다" → "Strategic Pause를 선택"
- **수동적 시청 → 능동적 분석**: "넷플릭스 봤다" → "업계 트렌드를 분석"
- **틀어놓음 → 자기주도 학습**: "유튜브 틀어놨다" → "자기 주도적으로 학습"
- **목적성 부여**: 의도 없던 공백에 "지속 가능한 성장", "커리어 재정비" 같은 목적을 사후 부여
- **영어 표현 차용**: "Strategic Pause"라는 영어 어휘로 격상 (기법 04와 결합)
