# 05. 공백기를 전략으로

> 쉰 게 아니라 투자한 것입니다

## Before (원본)

```
퇴사하고 3개월 동안 집에서 넷플릭스 보면서 쉬었습니다.
가끔 유튜브로 코딩 강의 틀어놨습니다.
```

## After (거품)

```
지속 가능한 성장을 위해 Strategic Pause를 선택, 업계 트렌드를 분석함.
신규 기술 스택을 자기 주도적으로 학습하며 커리어 재정비의 시기를 가짐.
```

## 변환 패턴 분석

- **휴식 → 전략적 선택**: 그냥 쉬었다는 사실을 지우고 "전략적으로·의도적으로 선택한 휴지기"로 재프레임 (위 After의 "Strategic Pause"는 한 표현 예시일 뿐, 매번 입력 맥락에 맞는 새 어구를 자유롭게 생성)
- **수동적 시청 → 능동적 분석**: 넷플릭스·유튜브 같은 수동적 시간 사용을 "분석·리서치·모니터링" 같은 능동성 어휘로 격상 (단, 거짓 행위는 만들지 않음 — 본인이 실제로 한 행위의 프레임만 격상)
- **틀어놓음 → 자기주도 학습**: 강의 틀어놓은 정도의 행위를 "자기 주도적 학습·체계적 역량 강화"로 격상
- **목적성 부여**: 의도 없던 공백에 추상적 목적("지속 가능한 성장"·"커리어 재정비"·"다음 챕터 준비" 같은 류)을 사후 부여
- **영어 표현 차용**: 영어 어구로 휴지기를 포장하면 격상 효과가 큼 (기법 04와 결합). 어떤 영어 어구를 쓸지는 매번 입력 맥락과 화자 톤에 맞춰 자유롭게 만들어낸다 — 위 After의 "Strategic Pause"에 매번 회귀하지 않는다.

### 변환 시 주의 (가장 중요)

위 After의 영어 어구·격상 표현("Strategic Pause"·"업계 트렌드 분석"·"커리어 재정비")은 이 한 입력에 대한 한 사례일 뿐 매번 써야 할 카탈로그가 아니다. 공백기 입력이 들어왔다고 매번 "Strategic Pause"로 회귀하지 않는다. 입력 맥락(이직 사이·번아웃 회복·학업 준비·가족 사정·여행 등)과 화자 톤에 맞춰 매번 새 영어 어구와 격상 표현을 자유롭게 만들어낸다. 핵심은 "휴식을 의도된 전략적 시기로 포장한다"는 메커니즘이지 특정 단어 선택이 아니다.
